# Setup Guide for GitDemo Project

## Prerequisites

### Required Software
- **Git** (latest version) - [Download Git](https://git-scm.com/download/win)
- **VS Code** (or any text editor)
- **Python 3.x** (for running sample application)
- **GitHub/GitLab Account** (optional for remote repository)

### Verify Installations
```bash
# Check Git version
git --version

# Check Python version (if installed)
python --version
