# Spring Country Code API

## 📌 Project Overview
A Spring Boot REST API that provides country information based on ISO country codes. The API supports case-insensitive search for country codes.

## 🚀 Features
- Get country by ISO code (case insensitive)
- Get all countries
- Proper error handling with HTTP status codes
- Logging with SLF4J
- Unit and integration tests with MockMVC
