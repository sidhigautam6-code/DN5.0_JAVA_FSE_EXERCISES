angular.json - Angular CLI configuration file, defines build options, 
  asset paths, and project settings

tsconfig.json - Base TypeScript configuration for the entire workspace

tsconfig.app.json - TypeScript configuration specific to the application,
  extends tsconfig.json

package.json - Project dependencies, scripts, and metadata

src/main.ts - Application entry point, bootstraps the root component

src/app/app.module.ts - Root module (or app.config.ts in standalone mode),
  declares components and imports dependencies

src/app/app.component.ts - Root component, serves as the main container

src/index.html - Main HTML page, contains <app-root> where the app renders
